# Tray UI Implementation Plan

> **For agentic workers:** Implement task-by-task in this session (inline execution). Do not commit unless the user asks.

**Goal:** Replace the `lightcapture-app` stub with a tray-only Windows front that toggles recording via `Ctrl+Shift+R` and exposes quality, capture source, output folder, and cursor in the tray menu.

**Architecture:** App crate only. `lightcapture-core` stays the engine. A Win32 message pump on the UI thread hosts `tray-icon` + `global-hotkey`. Settings persist to `%APPDATA%\LightCapture\settings.json`.

**Tech Stack:** Rust 2021, `tray-icon`, `global-hotkey`, `serde`/`serde_json`, `directories`, `rfd`, `single-instance`, `windows` (message pump + COM).

## Global Constraints

- Windows-only; MSVC; `cargo clippy --workspace --all-targets -- -D warnings`
- Engine stays in `lightcapture-core`; no WGC/MF in the app
- No egui, no visible window, no toasts, no live preview, no audio
- `#![deny(unsafe_op_in_unsafe_fn)]`; every `unsafe` block has `// SAFETY:`
- Hardware/tray/hotkey tests that need a desktop stay out of default `cargo test`
- Binary `expect` only in `main` after a user-facing message
